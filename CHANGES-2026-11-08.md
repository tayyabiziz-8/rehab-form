# Review fixes — 8 Nov 2026

Changes made on top of the Keraal Group 3 evaluation. Nothing in the evaluation logic was rewritten; the fixes are targeted.

## Fixed

1. **BlazePose aspect ratio** — `src/rehabform/keraal.py::load_blazepose`
   - Keraal stores BlazePose x as a fraction of image width and y as a fraction of image height (Group 3: 960 × 544). Using these raw values squashes horizontal distances to ~57% of vertical ones, so diagonal angles are wrong (true 45° reads ~30°).
   - `load_blazepose` now returns **pixel units by default**: x × 960, y × 544, z × 960 (MediaPipe's z is on roughly the same scale as x). New argument `image_size=(w, h)`; pass `image_size=None` for raw values. **Groups 1a/1b/2a/2b videos are 480 × 360 — pass that size for them.**
   - Every existing script that calls `load_blazepose` picks this up automatically.

2. **BlazePose landmark order** — same function
   - Previously the landmark order came from the JSON key order and only the set of names was checked. Landmarks are now placed by **name** in the canonical order (`BLAZEPOSE_ORDER`, from the dataset readme). Missing landmarks become NaN instead of crashing.

3. **Shoulder diagnostic vertical axis** — `scripts/diagnose_shoulder_angles.py`
   - `candidate_angles` used image "up" (−y) for Kinect too. Kinect's y points up, so its vertical reference was upside down and the "vertical 3D" candidate was penalised unfairly. New argument `vertical_positive_up` (False for BlazePose, True for Kinect).

## Added

4. **Offset-free Vicon evaluation** — `scripts/evaluate_keraal_vicon_offsetfree.py`
   - Compares BlazePose (2D and 3D variants) with Vicon using **change from the start pose** and **range of motion**, which cancel the fixed offset from ART targets sitting on segments.
   - Vicon angles use segment directions (shoulder→arm target, forearm→hand target, hips→chest), not targets as joints.
   - Resamples Vicon to video time, searches ±1 s lag, flips sign for signed angles if needed; reports r, change-from-start MAE and ROM error, by exercise and by participant.
   - Outputs: `outputs/keraal_vicon_offsetfree_per_recording.csv`, `outputs/keraal_vicon_offsetfree_summary.csv`.

5. **Tests** — `tests/make_synthetic_keraal.py`, `tests/test_keraal.py`
   - Synthetic Keraal folder (all five modalities, JSON keys in reversed order, known arm motion).
   - Tests: landmarks ordered by name; pixel conversion restores a 45° angle that raw values squash to ~30°; BlazePose and Kinect give the same vertical-reference shoulder angle.
   - All existing evaluation scripts were run on the synthetic folder after the change and complete without errors.
   - Side finding: on this synthetic data, where phone and Vicon agree exactly, `compare_keraal.py` still reports ~21° shoulder-abduction error — the fixed offset from the single Hips target and segment-mounted targets.

6. **Docs** — warning box at the top of `docs/Keraal Group 3 - Initial Angle Evaluation.md`; README table updated.
